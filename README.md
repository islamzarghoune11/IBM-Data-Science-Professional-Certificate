# IBM Data Science Professional Certificate

This repository contains my practical work and projects completed during the **IBM Data Science Professional Certificate** on Coursera.

The certificate covers the main stages of the Data Science workflow, from understanding a data science problem and working with data to analysis, visualization, machine learning, and applied projects.



## 📚 Certificate Overview

The program consists of **12 courses/modules** covering technical foundations, practical projects, and career development.

| #  | Course                                                    | Main topics                                           |
| -- | --------------------------------------------------------- | ----------------------------------------------------- |
| 01 | **What is Data Science?**                                 | Data Science fundamentals, roles, tools and skills    |
| 02 | **Tools for Data Science**                                | Jupyter, RStudio, GitHub, IBM Watson Studio           |
| 03 | **Data Science Methodology**                              | Data Science workflow and problem-solving methodology |
| 04 | **Python for Data Science, AI & Development**             | Python fundamentals, NumPy and Pandas                 |
| 05 | **Python Project for Data Science**                       | Practical Python project using real-world data        |
| 06 | **Databases and SQL for Data Science with Python**        | SQL, relational databases and Python integration      |
| 07 | **Data Analysis with Python**                             | Data cleaning, exploratory analysis and statistics    |
| 08 | **Data Visualization with Python**                        | Matplotlib, Seaborn, Folium and data visualization    |
| 09 | **Machine Learning with Python**                          | Regression, classification and clustering             |
| 10 | **Applied Data Science Capstone**                         | End-to-end Data Science project                       |
| 11 | **Generative AI: Elevate Your Data Science Career**       | Generative AI, LLMs and prompt engineering            |
| 12 | **Data Scientist Career Guide and Interview Preparation** | CV preparation, career development and interviews     |
